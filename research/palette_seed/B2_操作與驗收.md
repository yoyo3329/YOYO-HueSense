# HueSense B2 v0.1｜從既有單色池逐色生成五色

**本階段已在課程 1 分支開發**：Python `scripts/b2_greedy_select.py`、`tests/test_b2_greedy_select.py`、`ui/b2.html` 和 GitHub Actions `seed-b2-greedy.yml`。

## 本版真實資料的界線

- 來源：既有 63 組五色種子的所有原始 HEX，整理成 291 色的去重單色池。**這不是之前獨立 SQLite v0.2 的 1,085 色全庫。**
- 指定核心色：`#A85C45` 不在這 291 個色碼中，屬於外部使用者輸入；不宣稱它有 NCC/NRC 或 xkcd 的實證語意關聯。
- 輸出五色中第一色是輸入色，後四個一定是來源池既有 HEX。**不創造新的顏色，不進行心理分數、品牌偏好、角色配置或對比檢查。**

## B2 演算法

1. 將 HEX 轉成線性 sRGB，再以 Björn Ottosson 的 OKLab 轉換公式得到 L、a、b。
2. 已選集合從核心色開始，將其排除於後續候選之外。
3. 對尚未選中的每個候選 `c`，求它到**所有已選色**的 OKLab 距離最小值。
4. 選最大最小距離者。相同分數（差距在 1e-12 之內）時，按照 HEX 字典順序決定，保證相同輸入可重現。
5. 重複四次，輸出五色與每一步 `selected_hex`、`min_oklab_distance`、`evaluated_candidates`、`from_seed_ids`。
6. 固定版本 `b2-oklab-maximin-v0.1`，輸出來源版本及輸入 JSON 的 SHA-256。

**限制**：Max-Min 著重區辨度，不代表配色協調。它沒有重現 Colorgorical 原論文的完整心理偏好或色名模型。

OKLab 數學來源：https://bottosson.github.io/posts/oklab/

## GitHub Actions 驗收

`seed-b2-greedy.yml` 使用 GitHub Actions 執行真正 291 色資料、色彩轉換參考值、來源追蹤、確定性、極值最優性、不同資料池與 CLI 測試，並將核心色 `#A85C45` 的 JSON 結果保存成工作流程 artifact。執行狀態請以 Actions 頁面最新一次運行為準。

## 不需 Docker 的本機測試（最後可一次完成）

```powershell
py research/palette_seed/scripts/b2_greedy_select.py --anchor "#A85C45"
py -m unittest discover -s research/palette_seed/tests -p "test_b2_greedy_select.py" -v
```

直接開啟 `research/palette_seed/ui/b2.html`，可切換核心色、來源色池，看到五色與每一步選取分數，也可複製 HEX、匯出 JSON、執行一致性檢查。

## 沒有改動的部分

不修改根目錄 `compose.yaml`、舊版影像研究程式、正式網站、單色資料庫 v0.2 或 MySQL 主資料表；`ui/b2.html` 是獨立的離線測試頁面。
