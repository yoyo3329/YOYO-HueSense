如何真正切換成 1,085 色資料

  1. 把原始 SQLite 放在專案的 research/palette_seed/data/ 資料夾。
  2. 執行 py research/palette_seed/scripts/import_single_color_sqlite.py --inspect --database "你的檔案.sqlite"，先確認真實表名和欄位。
  3. 執行 py research/palette_seed/scripts/import_single_color_sqlite.py --database "你的檔案.sqlite" --output research/palette_seed/data/single_color_pool.json。
  4. 重新執行 B2；程式在找到此標準化 JSON 時會優先使用它。也可以把 JSON 載入本頁直接測試。

匯入器保留色彩原始資料列、連結到的關聯資料、來源與證據資料；同一 HEX 合併為一個候選，但不刪除它背後的不同來源記錄。匯入器只會複製原資料中存在的資訊，不自行補心理分數。
