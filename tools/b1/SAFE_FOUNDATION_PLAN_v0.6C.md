1. Project State Manifest
2. Accurate `npm run status`
3. Generic Style Workspace

## Hard safety boundaries

- Human Tone/Hue calibration stays PAUSED.
- v0.5 Holdout is not reused for retuning.
- v0.5 Candidate remains production-ineligible.
- Formal `color-relation-core.js` is protected.
- `public/js/app.js` is not changed or connected.
- Quiet Luxury is created only as a DATA_PENDING workspace; no synthetic evidence or fake validation.
- B3-D does not perform semantic naming or irreversible merging.

## Generic pipeline design

The v0.6C kernels accept explicit input/output paths. Y2K is only one workspace configuration. Future styles use the same runner once their real evaluation set and cache are available.

For Y2K, the generic pipeline includes a baseline reproduction gate: B1 must be physical-semantic exact (transport diagnostics may differ), while B2, B3-A and Relation Graph must be byte-for-byte exact.

## v0.6C self-test mode

The v0.6C one-chain reuses the already-proven Y2K B1 artifact so it does not redundantly decode 24 images again. The generic runner still supports full cache-only B1 for any READY workspace by omitting `--reuse-b1`.
