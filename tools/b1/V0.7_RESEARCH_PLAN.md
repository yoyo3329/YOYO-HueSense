# YOYO v0.7 — Perceptual Relation Redesign

## Research discipline

The retired v0.5 boundary-stress holdout may be used only to classify failure modes. It must not tune thresholds, select a formula, or validate v0.7.

## Resumable one-chain workflow

1. Failure taxonomy from retired holdout — diagnostic only.
2. Generalized hypothesis registry — pre-registered before new labels.
3. Perceptual Relation Contract v0.7 — Lightness, Chroma, Hue applicability, Hue relation, Overall Tone separated.
4. Fresh case builder — excludes all previously labeled pairs.
5. 24-case direct-human blind train lab.
6. Fit/freeze v0.7 candidate from train only.
7. Only after freeze, decrypt/materialize the preselected 12-case independent validation lab.
8. Direct-human blind validation.
9. First independent v0.7 validation against a pre-registered pilot gate.
10. Validation is read-only: it cannot retune or automatically promote production.

Run the same command at every stage: `npm run v0.7`. It resumes from the correct gate.

No human labels are fabricated by the installer.
