# A.2.2 Contract

A.2.2 is not A.3 and not Style Graph.

- A.2.1 masks are immutable hypotheses and are never deleted.
- A global/umbrella mask can provide scene/background evidence but cannot directly create LOCAL SPLIT/GROUP recovery evidence.
- Mask role is a multi-hypothesis routing label, not semantic truth.
- Semantic top labels and MNN are auxiliary evidence only.
- Recovery metrics are shown as RAW FOUNDATION and LOCAL-COMPONENT views.
- Proposal Information Value remains a vector; no scalar ranking score is authorized.
