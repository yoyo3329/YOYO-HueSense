# Baseline findings used by A.2.2

A.2.2 is grounded in the completed A.2.1 run and addresses evidence-quality issues only.

Key observed failure:

- Y2K PACK: all-mask union coverage = 99.13%, but after removing global/umbrella masks from **local recovery authority**, local union coverage is only ~7.11%.
- This demonstrates why global-context masks must remain preserved but cannot manufacture local SPLIT/GROUP recovery.
- Sticker Collage remains a positive Foundation split case.
- Fashion recovery remains partial/mixed.

A.2.2 therefore does not change SAM2, OpenCLIP, or thresholds used upstream. It changes only interpretation/routing/audit of upstream hypotheses.
